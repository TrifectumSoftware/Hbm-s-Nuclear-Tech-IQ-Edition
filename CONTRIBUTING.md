# NTM IQ Edition Contribution Guidelines

So in light of the sudden desire me (irislgtm) has had to fork ntm, and the possible future influx of contributors, i have decided
to change up the contribtuion guidelines a little because i thought the old ones didnt fit this zroject

- First, please make a fork then commit
  - Second, make sure your idea isn't absolute slop. I mean we have leeway for joke items much larger than ntm but lwk most of ntmmain is actually slop
  and i can see why bob hates them but like "peepee item dropped from pissing on the floor with 69 tam69 bombs while gooning to freddy iq that gives you 1 trillion geralds" is a bit much, even for me
- Third, you should have fun when developing this mod, if you are having issues or need advice you can ask but if you have an earnest feature you can discuss about it in the discord. Most likely your idea will never be turned down.
- Fourth, dont commit gradle changes, i already updated them so you can use them in intelliJ out of the box

Finally, i don't plan for any of these features to ever go into NTM, so if you contribute to this fork for like ultra serious features
scoped to what bob wants, you should probably go to ntmmain cause theyll end up merged back here anyway. The main point of the fork is to ignore what GBT and Bob in general say, which leaves us with
space to work on our own things.

The fork has no particular goal, and is about the same as regular NTMSpace.

INCASE UPSTREAM HAS ANY duplicated features, we will merge whoever has the better feature and scrap/rework features that are objectively worse than ours.
For example if bob implements an autofeeder which hardcodes some fluid cases to do x amount of hunger, of course ours is more detailed so ours will have credence.

Also, we will be using custom versioning.

Besides that, i have added an AI Policy instead of a blanket ban, cause i really dislike being unprofessional in these matters. Yes, i know it is an MC mod, But it is still a piece of software, and such things are not to be handled childishly
read the AI_POLICY.md for information
